## 微信开发者工具人工步骤

1. 按 `docs/miniprogram-production-acceptance.md` 配置 request、uploadFile、downloadFile 和业务域名，均为 `https://www.safety.sx.cn`。
2. API 根地址已统一为 `https://www.safety.sx.cn/api`，不得改回 IP、HTTP 或 Mock。
3. 微信开发者工具导入 `apps/miniprogram`，写入正式 AppID并保持域名校验开启。
4. 编译后依次验证登录绑定、图文、HTML、考试恢复、Canvas 签字、管理入口及订阅授权。
5. 上传版本 `0.1.0`，更新说明：`安全培训学习、考试、签字、项目管理与核心报表首个试用版本。`
6. 在公众平台选为体验版，完成体验人员验证后提交微信审核；平台审核结果不属于代码完成状态。

1. `www.safety.sx.cn`、HTTPS、80 跳转、Secure Cookie 和 22/80/443 端口已验证完成。
