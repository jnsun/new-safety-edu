## 微信开发者工具人工步骤

1. 在微信公众平台配置已备案 HTTPS request 域名；HTML `web-view` 使用时同时配置业务域名，实际上传/下载需要时再配置对应合法域名。
2. 在 `apps/miniprogram/config/env.js` 的 `trial` 和 `release` 填入同一 HTTPS API 根地址，不保留 IP/HTTP。
3. 微信开发者工具导入 `apps/miniprogram`，在项目详情绑定真实 AppID并开启域名校验。
4. 编译后依次验证登录绑定、图文、HTML、考试恢复、Canvas 签字、管理入口及订阅授权。
5. 上传版本 `0.1.0`，更新说明：`安全培训学习、考试、签字、项目管理与核心报表首个试用版本。`
6. 在公众平台选为体验版，完成体验人员验证后提交微信审核；平台审核结果不属于代码完成状态。

## 域名与 HTTPS 人工步骤

1. 使用已备案域名添加 A 记录指向 `140.143.247.55`，在腾讯云安全组放行 443；22 建议只允许管理员固定公网 IP，仍不放行 3000/5432。
2. 在服务器申请该域名证书（例如 Certbot）；证书必须位于 `/etc/letsencrypt/live/<域名>/fullchain.pem` 和 `privkey.pem`。
3. 把 `app/deploy/nginx.production.conf.example` 复制为 `/opt/safety-training/nginx.production.conf`，仅将两处 `__DOMAIN__` 替换为实际域名。
4. 在 `.env.production` 写入 HTTPS `PUBLIC_BASE_URL`、真实微信 AppID/AppSecret 和已审核模板 ID，保持权限 `600`，并删除或改掉一次性 bootstrap 密码变量。
5. 将 `app/docker-compose.production.yml` 作为生产 Compose 配置，执行 `docker compose --env-file .env.production up -d`；再验证 80 跳转、443 页面、Secure/HttpOnly Cookie 和刷新登录。
