# 安全生产教育培训小程序主要功能介绍

> 文档状态：依据当前 `apps/miniprogram`、API 接口和已确认规划整理  
> 更新日期：2026-09-20  
> 说明：本文同时记录已完成、部分完成和规划中的功能。Figma 原型或需求规划不等同于已经开发完成。

## 1. 产品定位

安全生产教育培训小程序是安全生产管理平台的员工移动端，服务于正式员工、外协人员、临时个人以及具有管理权限的管理人员。

小程序当前围绕以下核心闭环工作：

1. 微信登录及人员身份绑定；
2. 查看本人必须完成的培训任务；
3. 学习图文、结构化或 HTML 课件；
4. 参加正式考试，支持中断恢复、补学和管理员解锁；
5. 考试通过后由本人完成一次手写签字；
6. 项目入场教育由有权限的项目管理人员完成现场确认；
7. 本人查询培训记录、考试成绩、签字和消息；
8. 通过每日安全挑战、积分和排行榜开展自愿学习。

系统只记录培训、考试、签字、证书和项目确认等事实，不生成“可上岗”“禁止上岗”“准入有效”或人员通行凭证等结论。

## 2. 当前技术与运行方式

- 客户端：原生微信小程序 JavaScript、WXML、WXSS；
- 基础组件：TDesign Miniprogram 按需使用，自建培训领域组件；
- 数据访问：所有业务数据均通过后端 API 访问，小程序不直接连接数据库；
- 测试环境：微信开发版和体验版连接 `https://test.safety.sx.cn/api`；
- 正式环境：微信正式发布版连接 `https://www.safety.sx.cn/api`；
- 环境保护：客户端请求携带小程序环境标识，测试版默认禁止访问生产 API，正式版锁定生产 API；
- 当前实际页面：18个；
- 当前实际底部导航：待办、我的记录、消息、我的。

## 3. 用户与权限

### 3.1 普通人员

普通人员能力由本人有效人员档案和有效账号自然获得，不需要管理员另外授予“普通学习人员”角色。

普通人员只能操作本人范围内的数据，包括：

- 本人培训任务；
- 本人课件学习进度；
- 本人考试和答案；
- 本人手写签字；
- 本人培训记录；
- 本人证书；
- 本人消息和资料变更申请。

### 3.2 管理人员

当前小程序可按服务端返回的管理角色显示“培训管理”入口，包括：

- 公司管理员；
- 组织负责人；
- 组织管理员；
- 项目管理员。

所有数据范围和操作权限均由 API 再次校验，前端隐藏按钮不能替代服务端鉴权。

## 4. 当前已完成的主要功能

### 4.1 微信登录

当前已完成：

- 通过 `wx.login` 获取临时代码；
- 后端调用微信接口识别微信身份；
- 已存在有效微信绑定时直接建立登录会话；
- 账号或人员停用后不能继续使用原会话访问业务；
- access token 与可撤销 refresh session；
- 退出当前设备和退出全部设备；
- 测试版和正式版 API 环境自动隔离。

### 4.2 首次身份绑定

当前已完成：

- 优先调用微信 `getPhoneNumber` 获取微信已验证手机号；
- 手机号唯一匹配 active 人员，且组织关系没有冲突时，可直接完成微信、账号和人员绑定；
- 未匹配、多条匹配、部门不一致、账号冲突或微信冲突时，不自动登录；
- 无法自动匹配时填写姓名并选择现有组织，提交身份确认申请；
- 申请按组织范围路由给有权限的管理员；
- 没有有效组织管理员或出现跨范围冲突时升级公司管理员处理；
- 同一微信身份和同一手机号的重复待审核申请进行幂等控制。

短信验证码保留为微信绑定、微信换绑、修改手机号和手机号真实性验证的备用方式，不作为独立登录方式。

### 4.3 身份绑定审核状态

申请人可以查看：

- 待部门审核；
- 已升级公司管理员处理；
- 已通过；
- 已驳回及驳回原因；
- 数据冲突待人工处理。

### 4.4 外协人员和临时个人注册

当前支持：

- 选择外协人员或临时个人；
- 选择外协单位、责任经营实体和申请项目；
- 上传本人照片；
- 提交注册或加入项目申请；
- 进入待审核状态。

### 4.5 待办首页

待办首页展示本人必须完成的培训任务，包括：

- 培训名称；
- 培训类型；
- 截止时间；
- 当前状态；
- 学习进度；
- 当前下一步；
- 进入任务按钮。

任务优先级为：

1. 未完成的三级教育；
2. 其他逾期任务；
3. 临近截止任务；
4. 普通任务。

三级教育优先展示只用于行动引导，不阻止人员查看或完成其他培训。

### 4.6 培训任务详情

任务详情当前支持：

- 培训名称、类型、项目或组织、截止时间；
- 学习、考试、签字、完成四阶段进度；
- 全部必学课件列表；
- 每个课件的完成状态；
- 考试状态、考试次数和分数；
- 签字状态；
- 项目确认状态；
- 根据服务端状态显示唯一有效的下一步操作。

所有必学课件均可查看，不逐级解锁；全部必学课件完成后才允许进入考试。

### 4.7 图文与结构化课件

当前支持：

- 普通图文课件；
- 原生结构化课件；
- 单文件 HTML 互动课件；
- 记录课件打开、到达末尾和本人确认完成；
- 保存当前内容块和学习百分比；
- 再次进入时恢复上次学习位置；
- 补学阶段重新完成必学内容；
- 加载失败、保存失败和重试提示。

结构化课件当前内容块包括：

- 图文知识卡；
- 正确做法与错误做法；
- 操作步骤；
- 随堂单选、多选或判断；
- 情境选择及选择后果；
- 三点总结。

随堂练习用于理解和复习，不代替正式考试，也不影响正式考试成绩。

### 4.8 HTML 互动课件

HTML 课件通过受控 `web-view` 打开：

- 使用短时授权地址；
- 不公开私有文件目录；
- 文件访问继续经过服务端权限校验；
- 课件学习完成仍由现有培训任务流程记录。

### 4.9 正式考试

当前考试支持：

- 固定试卷；
- 简单随机组卷；
- 单选、多选和判断；
- 单题显示；
- 考试倒计时；
- 自动保存答案；
- 退出或网络中断后恢复原 attempt；
- 恢复已保存答案和剩余时间；
- 交卷前检查；
- 服务端评分；
- 显示得分、是否通过和考试次数；
- 幂等交卷。

正确答案和评分规则不会在正式交卷前返回客户端。

### 4.10 补学、锁定和解锁

当前支持：

- 考试未通过后进入“需补学”；
- 按要求重新完成必学内容后才允许再次考试；
- 达到最大考试次数后进入“已锁定”；
- 有权限的管理员填写原因后解锁；
- 解锁只允许参加新的考试，不修改或删除历史考试成绩。

### 4.11 本人手写签字

当前支持：

- 考试通过后展示培训记录摘要；
- Canvas 手写签字；
- 清空重写；
- 提交前预览；
- 有效书写校验；
- 正式提交二次确认；
- 签字时间、设备信息和记录摘要关联；
- 正式签字提交后本人不能覆盖。

### 4.12 本人培训记录

本人可以查看：

- 培训名称；
- 培训类型；
- 完成时间；
- 考试最终成绩；
- 是否通过；
- 签字状态；
- 学习课件及版本；
- 历次考试事实；
- 项目现场确认事实。

普通人员不能查看其他人员的记录。

### 4.13 消息中心

当前支持：

- 查看本人系统内消息；
- 培训提醒；
- 临近截止或逾期提醒；
- 管理员催办；
- 审核结果；
- 点击消息标记为已读。

### 4.14 我的页面

当前“我的”页面集中提供：

- 姓名、人员类型、组织和照片；
- 修改本人照片；
- 脱敏手机号；
- 通过微信重新认证后短时查看完整身份证号；
- 本人证书和到期时间；
- 当前管理角色和授权范围；
- 安全积分摘要；
- 申请调换部门；
- 资料与关系变更申请；
- 微信订阅消息授权；
- 生成本人敏感资料文件；
- 有效登录设备管理；
- 修改手机号；
- 退出当前设备；
- 退出全部设备；
- 有权限时进入培训管理。

### 4.15 资料与关系变更申请

当前支持：

- 姓名等资料更正；
- 人员类型更正；
- 外协单位变更；
- 内部责任经营实体变更；
- 调换主部门；
- 上传必要附件；
- 查看申请状态和审核意见；
- 填写原因后撤回允许撤回的申请。

手机号修改和微信换绑使用专门的身份验证流程，不能通过普通资料申请绕过验证。

### 4.16 移动培训管理

有权限的管理人员可以在小程序中进行高频现场操作：

- 查看本人权限范围内的未完成人员；
- 查看待审核申请；
- 审核身份绑定和其他允许的申请；
- 催办培训；
- 填写原因后解锁考试；
- 确认项目人员已到场并接受现场交底。

复杂的人员、组织、课件、题库、模板和培训下发配置继续在 Web 管理后台完成。

### 4.17 每日安全挑战

当前已完成独立的每日安全挑战：

- 每日从启用题库中抽取题目；
- 显示题目进度；
- 支持单选和多选；
- 首次答对获得积分；
- 答错不扣分并显示解析；
- 重复练习不重复计分；
- 由服务端计算并写入不可变积分流水。

每日挑战是自愿学习，不影响正式培训、考试、补学、签字或项目确认。

### 4.18 个人与部门排行榜

当前支持：

- 本月个人积分；
- 累计积分；
- 个人月榜；
- 本人不在前列时显示本人附近排名；
- 部门月榜；
- 部门积分、参与人数、总人数和参与率；
- 切换历史月份。

排行榜不显示手机号、身份证、人员照片或培训考试成绩。

## 6. 已规划但尚未开发完成的功能

### 6.1 五项底部导航

规划调整为：

> 待办 / 记录 / 闯关 / 消息 / 我的

当前代码仍为：

> 待办 / 我的记录 / 消息 / 我的

因此以下内容尚未完成：

- 新增“闯关”主 Tab；
- 将每日挑战、小游戏、积分和排行榜集中到闯关中心；
- 将“我的记录”文案精简为“记录”；
- 为待办、闯关和消息设计统一角标规则；
- 移除待办首页中与强制培训争夺注意力的大型挑战卡。

### 6.2 安全闯关中心

Figma 原型已经规划，但当前小程序代码尚未建立独立闯关中心页面。

规划内容包括：

- 今日挑战；
- 本月积分和累计积分；
- 本月个人排名；
- 安全小游戏入口；
- 排行榜预览；
- 积分规则入口；
- 未开放游戏状态。

### 6.3 安全生产小游戏

当前只完成每日安全答题，以下独立小游戏尚未开发：

- 找隐患；
- 步骤排序；
- 情景选择；
- 应急处置选择；
- 安全知识快答专题；
- 游戏专题和关卡列表；
- 通用游戏过程页面；
- 闯关结果和知识点复习页面。

小游戏必须与正式培训分开。游戏积分不能改变正式培训完成状态、考试成绩或任何人员资格结论。

### 6.4 独立积分明细与规则页面

当前已能展示积分摘要和排行榜，但以下功能尚未形成独立页面：

- 积分流水明细；
- 每笔积分的来源；
- 重复练习不重复计分的说明；
- 异常积分作废记录；
- 完整积分规则。

当前版本不规划积分商城、奖品兑换、库存或线上发奖流程。

### 6.5 “我的”页面拆分

当前个人信息、证书、角色、设备、手机号修改和资料申请集中在一个页面中，后续计划拆分为：

- 个人资料详情；
- 证书与管理角色；
- 账号安全与设备；
- 资料与关系变更；
- 个人中心总览。

拆分只调整信息架构，不改变现有业务权限。

### 6.6 Figma 新版 UI 接入

当前已经在 Figma Make 中制作了27页面高保真交互原型，但尚未逐页接入原生微信小程序。

仍需完成：

- 将 Figma Make 原型转换或整理为标准 Figma Design 文件；
- 校正原型中与现有业务规则冲突的演示内容；
- 建立小程序可复用组件及状态 Variants；
- 将新版五 Tab、闯关中心和拆分后的个人中心接入代码；
- 完成375px、390px和430px宽度适配；
- 真机检查微信胶囊、底部安全区、键盘弹起和长文本；
- 验证加载、空数据、失败、无权限、禁用和提交中状态。

Figma 原型不能直接作为原生小程序代码使用。

### 6.7 微信订阅消息正式配置

订阅消息适配器和授权入口已经存在，但正式发送仍依赖微信公众平台配置：

- 培训任务模板 ID；
- 截止或逾期模板 ID；
- 模板字段名称；
- 用户逐次授权；
- 微信发送额度和平台审核状态。

未配置或发送失败时，系统内消息继续保留，不阻塞培训业务。

### 6.8 短信验证服务

短信是微信手机号能力不可用时的备用验证方式。代码已支持验证码有效期、发送频率、错误次数和使用后消费，但实际发送依赖外部短信网关：

- `SMS_SEND_ENDPOINT`；
- `SMS_SEND_TOKEN`；
- 服务商模板及签名审核。

短信服务没有配置时，不影响已经能够使用微信 `getPhoneNumber` 的人员自动匹配。

### 6.9 真实培训内容与题库持续建设

系统已经具备结构化课件、题库和每日挑战能力，但实际可用性仍依赖内容建设：

- 公司级、部门级和岗位级三级教育内容；
- 项目入场教育通用内容；
- 野外作业、交通、消防、用电、极端天气和应急处置课程；
- 正式考试题库；
- 每日挑战题库；
- 找隐患图片及危险区域标注；
- 步骤排序和情境选择关卡；
- 法律法规、制度和课程版本定期复核。
