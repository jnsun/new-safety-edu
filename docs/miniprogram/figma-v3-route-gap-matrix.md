## 分批实施边界

1. **第一批：基础与一级页**：统一令牌、五栏导航、待办、记录、闯关中心、消息、我的。
2. **第二批：学习闭环**：任务详情、结构化课件、HTML、考试、签字、培训记录详情。
3. **第三批：身份与管理**：登录、绑定、审核状态、注册、资料变更、培训管理、身份审核。
4. **第四批：游戏与个人二级页**：游戏关卡/结果/积分页，以及个人资料、证书授权、账号安全独立页。

第四批中需要后端新数据的部分先完成可运行 UI 和明确空/未开放状态，不在客户端伪造积分、关卡或授权事实。
