# 培训五步流程本地隔离操作记录

日期：2026-09-21

环境：本机 Admin `http://localhost:5174`、本机 API、独立 PostgreSQL `training_workflow_e2e_test`
数据：脚本生成的匿名隔离数据，不含真实人员资料

## 连续操作

1. 登录隔离管理员账号，打开 `/training-dashboard`。
2. 点击“新建培训”，真实进入 `/training/new`，不是隐藏演示地址。
3. T03 填写培训名称、日常/年度培训和说明；向后再向前，内容仍保留。
4. T04 选择已发布课件并保存模板；页面显示模板已由接口保存，而非内存假保存。
5. T05 保持日常培训默认不考试；另由自动专项检查验证项目入场教育无法关闭考试、随机试卷题量不足会被服务端阻断。
6. T06 连续预览显示当前名称、说明、课件顺序、考试、签字和项目确认规则；此时数据库没有生成批次或任务。
7. T07 选择完整组织并执行服务端预检。覆盖抽屉返回 2 名纳入人员、1 名停用人员排除及原因。
8. 点击“确认下发”。T08 返回真实批次标识、2 项系统任务、1 名排除、0 名失败，外部通知显示“未配置，不影响任务下发”。
9. 点击“查看本批次培训进度”，进入 `/records?batchId=<新批次>`；列表自动定位该批次并显示 2 条实际进度。

## 自动补充验证

`pnpm smoke:training-workflow` 在相同隔离数据库中验证了就地创建并发布课件、题库/题目、固定/随机试卷、项目入场教育、非法范围、空项目、重复确认、旧预检失效、快照和学习端读取。机器可读结果保存在 `training-workflow-smoke.json`。
