# 管理员简明操作

1. 用管理员用户名和密码登录后台；首次进入后从右上角修改密码。
2. 在“人员与账号”逐人添加，或按导入模板上传 CSV/XLSX。
3. 在“组织与项目”建立组织、项目并维护项目成员。
4. 在“课件与模板”新建图文课件或上传单文件 HTML，确认内容后发布版本。
5. 按培训类型建立模板，并排列必学课件。
6. 在“题库与试卷”维护单选、多选、判断题，再建立固定试卷或随机规则。
7. 在“培训安排”选择模板、人员/组织/项目、截止时间和考试参数后下发。
8. 在“进度与记录”选择培训，查看未完成原因、学习进度、考试和签字状态。
9. 在“人员与账号”处理档案绑定/注册申请，在“进度与记录”处理资料变更申请。
10. 在权限范围内勾选人员并催办；短时间重复催办会自动去重。
11. 对已锁定人员填写原因后解锁；历史考试成绩不会被修改。
12. 在线下培训页填写真实培训时间、内容、授课人和参加人员；线下学习不会自动判定考试通过。
13. 对项目入场教育，在人员本人签字后确认“已到场、已接受现场交底”。
14. 在“报表与设置”查询三级教育台账、记录卡、签到表、成绩单和年度统计，可打印或导出 CSV。

所有列表和报表默认脱敏。不要在备注中填写完整身份证号、密码或微信密钥。
