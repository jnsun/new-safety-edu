## 业务边界与核验缺口

- “公司复核”仅查看及问题退回，不要求逐批确认。这是用户已确认规则，与 M15 的“确认”按钮冲突，因此未接入确认调用。
- 草稿/提交/退回/作废仍使用原有 API、权限与历史数据模型；只为历史对比在既有读取接口上追加修订快照，未更改数据库结构、未修改财务或培训。
- M08D 本轮只实现真实站内提醒；短信和微信订阅消息的实际送达并未接入该操作，界面明确区分“创建站内提醒”与外部渠道送达。
- 当前机器没有可用的本地月报认证测试环境或隔离数据库配置，未获取本地带真实数据的 1440×1000 截图。不能将 Figma 截图、构建通过或静态检查记为业务/视觉通过。
- 尚需逐页视觉对照及隔离数据回归：修订、作废后重填、无项目并发变更、整批重提与历史、公司退回后再次提交、配置错误反馈。当前 UI 静态回归只断言路由与关键保护代码存在，不能替代浏览器操作。
