# 管理员简明操作

## Day 1 基础资料

1. 使用一次性 bootstrap 创建的 company_admin 登录。
2. 在“组织与项目”先创建公司、经营实体或部门，再创建项目并指定唯一管理责任实体。
3. 在“人员与账号”上传个人照片后逐人创建，或按 `docs/import-templates/persons.csv` 导入。
4. 创建管理员账号后，通过角色接口授予不超过当前账号范围的组织或项目权限。
5. 小程序用户授权手机号；唯一匹配的在用人员自动绑定，其他情况进入绑定审核。

普通列表仅显示脱敏身份证信息。仅在单人编辑且有明确权限时才能读取完整值，该读取会写审计日志。
