## 0. 设计主张

**「深绿底座上的黄绿指针」**

这套界面服务两类人，他们看的是同一件事的两面：

- **员工（小程序）**：在野外、在手机竖屏上、信号不稳、只想尽快知道"我现在该做什么"。界面必须一眼给出唯一的下一个动作。
- **管理员（后台）**：在办公室桌面上，要在一屏里看几百人的完成状态、找出没完成的人、下发和催办。

统一语言是：**深墨绿负责权威与承载，亮黄绿负责"就是这里"，青绿负责品牌识别，橙只负责异常。**

三条硬规则：

1. **黄绿只给动作，不给装饰。** 一屏之内亮黄绿的面积越小，它越有效。它出现的位置只有一个含义：现在点这里。
2. **深墨绿只在两个地方大面积出现**：员工端的欢迎区/主任务卡，后台的左侧导航与权威数据面板。它不用于正文区背景。
3. **青绿是身份，不是按钮色。** 青绿在白底上的对比度只有 3.27:1，达不到正文标准，因此它只用于图形、渐变、大面积色块和 logo；凡是需要"文字级可读"的场合一律降一档到 `brand-text`。

## 1. 色彩系统

### 1.1 品牌色 Brand — 来自 logo 主环青绿

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--brand-ink` | `#04302A` | 最深墨绿。员工端欢迎区、主任务卡底色；后台侧栏底色 |
| `--brand-deep` | `#075445` | 深青绿。权威数据面板、深色卡片次级层 |
| `--brand` | `#12A17D` | 品牌主青绿（logo 主环）。图形、进度条、图标、大面积色块 |
| `--brand-strong` | `#0C8567` | 青绿的悬停/按下；可读下限（4.6:1），可用于 16px 以上文字 |
| `--brand-text` | `#0A7A5F` | **青绿系唯一允许做正文和链接的档位**（5.3:1） |
| `--brand-soft` | `#E4F4EF` | 浅底：选中态、信息条、标签底 |
| `--brand-line` | `#B9E1D6` | 浅描边、分隔 |

### 1.2 强调色 Accent — 来自 logo 黄绿分片

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--accent` | `#C9F16B` | **主按钮底色**（配 `--brand-ink` 文字，11.14:1）。也用于 Hero 装饰块、进度强调 |
| `--accent-strong` | `#B4E247` | 黄绿的悬停/按下 |
| `--accent-soft` | `#EEFAD2` | 浅底：待办计数、标签 |
| `--accent-ink` | `#4A6600` | 黄绿浅底上的深色文字（5.1:1） |

> **主按钮为什么是黄绿底而不是青绿底？** 青绿 `#12A17D` 配白字只有 2.9:1，配深字也不理想。参考图给出的解法很干净：亮黄绿底 + 深墨绿字，对比度 11.14:1，同时黄绿和青绿是 logo 里就有的邻近色，识别上是同一家。这是本规范对现有 `app.wxss` 里 `.primary { background: var(--action) }` 的**主要修正**。

### 1.3 中性色 Neutral

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#0F1A16` | 标题与正文（带绿相的黑，比纯黑柔和） |
| `--ink-soft` | `#33443D` | 次级正文、表单值 |
| `--muted` | `#61736B` | 说明、元信息、占位（白底 5.03:1，画布 4.62:1） |
| `--line` | `#E1E8E4` | 常规分隔与描边 |
| `--line-strong` | `#C9D5CF` | 输入框、次级按钮描边 |
| `--canvas` | `#F3F6F3` | 页面底色（比现有 `#F4F5F7` 多一点绿相） |
| `--surface` | `#FFFFFF` | 卡片与容器 |
| `--surface-soft` | `#F7FAF8` | 卡片内嵌层、表头 |

### 1.4 语义色 Semantic — 来自 logo 的橙与蓝分片

| 令牌 | 值 | 浅底 | 用途 |
| --- | --- | --- | --- |
| `--success` | `#0F7A57` | `#E3F4EC` | 已完成、通过、已确认 |
| `--warning` | `#A85A0A` | `#FDF1E2` | 待补学、即将到期、需补学后重考 |
| `--danger` | `#B8321F` | `#FBEAE6` | 未通过、已锁定、逾期、不可用 |
| `--info` | `#2A5FA8` | `#E8F0FA` | 中性提示、外部链接、受控 HTML 课件标识 |

> **为什么用 logo 里的橙做警示而不是通用红？** logo 分片里已经有橙，用它当警示能把"平台自带色"和"系统报错色"绑在一起；`#B8321F` 是它的深色可读版（5.98:1）。这套系统里**红和橙合并成一个档位**，需要区分轻重时靠文案（「待补学」vs「已锁定」）和图标，不靠再加一种颜色。

### 1.5 数据可视化色序

图表按此顺序取色，不额外发明：`#12A17D` → `#C9F16B` → `#2A5FA8` → `#A85A0A` → `#61736B` → `#0C8567`。
例外：**财务/金额相关图表沿用中国习惯——涨用红 `#B8321F`、跌用绿 `#0F7A57`**（应收账款模块）。

### 1.6 渐变

只保留两条，均由 logo 的两个主色生成，且方向固定 `135deg`：

```
--gradient-brand: linear-gradient(135deg, #12A17D 0%, #075445 100%);   /* 品牌面 */
--gradient-hero:  linear-gradient(135deg, #075445 0%, #04302A 100%);   /* 员工端 Hero 深底 */
```

页面和组件**不得自行声明渐变**（这一条沿用 `scripts/check-miniprogram-ui-system.mjs` 里已有的约束，只是把 `--blue-gradient` 换成 `--gradient-brand`）。

## 3. 形状与空间

### 3.1 圆角

| 令牌 | 小程序 | Web | 用途 |
| --- | --- | --- | --- |
| `--radius-card` | 36rpx | 16px | 卡片、面板（沿用小程序现值） |
| `--radius-panel` | 28rpx | 12px | 内嵌分区、表格容器 |
| `--radius-control` | 24rpx | 8px | 按钮、输入框 |
| `--radius-chip` | 999rpx | 999rpx | 胶囊标签、筛选器 |
| `--radius-tile` | 18rpx | 6px | 图标底、计数徽标 |

大圆角是本套视觉的签名特征（参考图里卡片和按钮都是明显圆角），但**圆角只表达容器层级**：不要把每段文字都包成胶囊。

### 3.2 间距

基础单位 4px / 8rpx。常用：`8 / 12 / 16 / 24 / 32`（px）、`16 / 24 / 32 / 48 / 64`（rpx）。
- 页面水平内边距：小程序 32rpx；后台 1440px 视口 28px。
- 卡片内边距：小程序 32rpx；后台 20–24px。
- 列表行最小高度：小程序 104rpx；后台 48px。

### 3.3 阴影

```
--elevation:        0 8rpx 24rpx rgba(4, 48, 42, .05);      /* 常规卡片 */
--elevation-raised: 0 18rpx 42rpx rgba(4, 48, 42, .14);     /* 主任务卡 */
--elevation-brand:  0 12px 32px rgba(4, 48, 42, .18);       /* 深色权威面板 */
```

阴影色相统一带绿（`rgba(4,48,42,…)`），不用纯黑，避免灰调与画面里的青绿打架。**筛选条一律无阴影。**

### 3.4 栅格

- 小程序：单列流式，宽度 750rpx，最大内容宽 690rpx。
- 后台：左侧导航 224px 固定，顶栏 64px；内容区 1440px 视口 28px 内边距、1280px 收至 22px、1920px 放宽至 48px；页面级禁止横向滚动，宽表只在表格容器内部滚动。

## 4. 组件规范

### 4.1 按钮

| 变体 | 底 | 字 | 描边 | 用途 |
| --- | --- | --- | --- | --- |
| Primary | `--accent` | `--brand-ink` | 无 | 每个界面**唯一**的主操作 |
| Primary-dark | `--brand-ink` | `#FFFFFF` | 无 | 深色 Hero 内部的反白动作（如"继续完成"） |
| Secondary | `--surface` | `--brand-text` | `--line-strong` | 次要动作、返回 |
| Ghost | 透明 | `--brand-text` | 无 | 行内动作、表格链接 |
| Danger | `--danger-soft` | `--danger` | 无 | 解锁、作废、停用等需二次确认的动作 |

高度：小程序 96rpx（mini 变体 72rpx），圆角 `--radius-control`，字重 600。
按下态：`opacity .82` + `scale(.995)`（沿用现有 `.tap-active`）。
焦点态（Web）：`3px` 半透明青绿轮廓 + `2px` 偏移。

> **一屏一个 Primary。** 员工端每一屏只应有一个黄绿主按钮，它就是当前唯一该做的事。

### 4.2 卡片

- **卡片 Card**：白底 + `--line` 描边 + `--radius-card`，是默认容器。
- **深色卡 Ink Card**：`--brand-ink` 底 + 白字 + `--elevation-brand`。用于员工端"现在先做"的主任务卡；一张页面**最多一张**。
- **黄绿卡 Accent Card**：`--accent` 底 + `--brand-ink` 字。用于"今天的关键动作"（如每日挑战卡）。与深色卡不同屏出现。
- **无边框卡 Flat**：只靠 `--canvas` 背景和白底的分层，用于筛选面板。

### 4.3 胶囊筛选器 Chip

筛选器**一律用胶囊，不用下拉菜单**（这条是既有约定，本规范继续沿用）：

- 默认：白底 + `--line` 描边 + `--muted` 字，高 56rpx（Web 28px）
- 选中：`--brand-soft` 底 + `--brand-text` 字，**去掉描边**，字重 650
- 横向可滚，滚动条隐藏；一组内不超过 7 个

### 4.4 状态标签 Tag

| 状态 | 底 | 字 | 文案示例 |
| --- | --- | --- | --- |
| 进行中 | `--brand-soft` | `--brand-text` | 待学习 / 进行中 |
| 待补学 | `--warning-soft` | `--warning` | 需补学后重考 |
| 已锁定 | `--danger-soft` | `--danger` | 考试次数已用完 |
| 已完成 | `--success-soft` | `--success` | 已完成 / 已签字 |
| 待确认 | `--info-soft` | `--info` | 待现场确认 |
| 中性 | `--surface-soft` | `--muted` | 未开通 / 不适用 |

标签一律胶囊形，高 44rpx（Web 22px），Micro 字阶。**标签不是按钮**，不可点击的标签不得有悬停态。

### 4.5 任务行 Task Row

员工端和后台共用的核心列表单元：

```
[标题            ] [状态标签]
[类型 · 截止时间            ]
[────── 进度条 ──────]
[下一步：去考试           ›]
```

- 整行是**真按钮**（`<button>` / `aria-role="button"`），不是包了 `bindtap` 的 view。这一条项目里已有校验脚本约束（`check-miniprogram-ui-system.mjs` 第 46–50 行），本规范继续执行。
- 主任务行用深色卡 + 黄绿 CTA；其余任务行用白卡 + 青绿进度条。

### 4.6 进度

- 轨道 `#E6EAE0`，高 12rpx / 6px，胶囊端。
- 填充：默认 `--brand`；**当任务逾期或处于补学状态时切换为 `--warning`，不切红**（红留给"已锁定"）。
- 进度条必须带 `aria-label`（现有代码已有此约定）。

### 4.7 表单

- 输入框：白底 + `2rpx --line` 描边 + `--radius-control`，高 96rpx。
- 聚焦：描边变 `--brand`，底不变（不做发光）。
- 错误：描边 `--danger`，下方 `--danger` 文字说明，不用红色底填满输入框。
- 禁用：`--canvas` 底 + `--muted` 字 + `opacity .65`。

### 4.8 空状态 / 错误状态

四类状态**必须分别呈现，不能共用一句"暂无数据"**：

| 状态 | 图标底 | 标题色 | 动作 |
| --- | --- | --- | --- |
| 加载中 | `--brand-soft` / `--brand` | `--ink` | 无 |
| 空数据 | `--brand-soft` / `--brand` | `--ink` | 提供下一步（如"去安全闯关"） |
| 筛选无结果 | `--brand-soft` / `--brand` | `--ink` | "切换上方条件" |
| 请求失败 | `--danger-soft` / `--danger` | `--danger` | 重新加载 |
| 无权限 | `--surface-soft` / `--muted` | `--ink` | 返回 |

图标底为 88rpx 圆形，图标 48rpx。

### 4.9 导航

- **小程序**：自定义 TabBar 5 项（待办 / 记录 / 闯关 / 消息 / 我的），白底 + `--line` 上边线，选中项 `--brand-text` 字 + `--brand` 图标，未选中 `--muted`。
- **Web**：左侧 224px 深墨绿侧栏（`--brand-ink` 底），菜单行 46px、圆角 8px；选中项 `--brand` 12% 透明底 + `--accent` 文字与左侧 3px 黄绿指示条。顶栏白底 64px。

> 后台侧栏用深墨绿是一个**明确变化**：现在的 `DESIGN.md` 定义的是浅色壳。深侧栏能把管理端和员工端拉到同一品牌下，同时让浅色内容区获得更强的对比。

## 6. Logo 与图标

Logo 为青绿 + 黄绿 + 蓝 + 橙 + 灰的圆环分片。

> ⚠️ 目前画布上的 Logo 是**按结构矢量重绘的示意版本**（青绿主环占 0–250°，其余四段依次切入，
> 分片之间留 3° 缝隙）。正式矢量资产（AI / SVG）到位后整组替换即可 ——
> 色值、留白比例、禁用规则都不需要改。

### 6.1 四种处理

判断依据只有一条：**底色深浅**。深底反白，浅底彩色，尺寸小于 24px 一律单色。

| 场景 | 处理 | 尺寸 |
| --- | --- | --- |
| 小程序登录页 | 居中，彩色版；下方留 40rpx 再排标题 | 宽 180rpx（90px） |
| 小程序 TabBar | 只用青绿主环，去掉彩色分片 | 48rpx（24px） |
| 小程序应用图标 | 深绿底 `--brand-ink` + 黄绿单色环 `--accent`，圆角 22、四周留白 22% | 1024×1024 导出 |
| Web 后台侧栏 | 深绿底上取黄绿单色 `--accent`，比纯白更贴品牌 | 24px |
| 后台 / 文档页眉 | 彩色原样，右侧留 12px 间距接标题 | 高 24px |
| 登录页 / 邮件头图 | 深绿底反白（`#FFFFFF`），可放大到 96px | 96px |
| 图片、深色照片上 | 一律用反白版；不许在照片上直接压彩色版 | ≥ 48px |

### 6.2 留白与最小尺寸

- **留白 = 圆环外径的 25%**。160px 的 Logo 需要一块 **240×240 的净空区**（160 + 40×2）。
  小程序登录页 Logo 宽 180rpx，净空区就是 270rpx。
- 写 CSS 时用 `padding`，不要用 `margin` —— margin 会被相邻元素折叠掉。
- 净空区内不许出现任何其他元素：文字、图标、边框、分割线都不行。浅底上的留白靠"什么都不放"实现，
  不要画一个白色方块去凑。
- **24px（48rpx）是分片色的下限**。低于这个尺寸，黄绿 / 蓝 / 橙三段只剩 1–2 像素宽，
  在手机上会变成脏点而不是分片。所以 TabBar、列表前缀、应用图标一律用单色。

### 6.3 禁止用法

| 错法 | 说明 |
| --- | --- |
| 拉伸变形 | 横纵比锁死。只允许等比缩放，不许拉长或压扁。 |
| 旋转 | 只允许水平正放。不做倾斜，也不做环绕排列。 |
| 加投影 | 不加投影、不加发光。靠留白与底色把 Logo 分离出来。 |
| 改分片色相 | 五个分片色相固定。不许改成品牌色、单色或自定义配色。 |
| 描边 / 压暗当水印 | 不加水印、不加描边。半透明只用于图片上的反白版。 |
| 重排 / 拆分使用 | 不许把分片拆开当装饰图形，也不许重排成别的形状。 |

### 6.4 图标

- 画在 **24×24 画布**里，主体压在 **20 圆 / 18 方**的对齐框内，四周留 2 单位呼吸。
- **描边 2**，端帽与拐角一律 `ROUND`。方头尖角只适用于极简几何字标，图标里一律不用。
- 线宽只三档：`1.5`（16–20px 小图标）、`2`（默认，24px）、`2.5`（32px 以上强调图标）。
  同一组图标里不许混用。
- 只用四种品牌色：`--brand`、`--brand-deep`、`--accent`（仅用于"当前 / 强调"），
  内嵌细节线用 `--muted`、`--line-strong`。禁止渐变、投影、多色描边。
- 首批 10 个：安全防护 / 课件学习 / 在线考试 / 学习记录 / 证照管理 / 到期预警 / 人员组织 /
  统计报表 / 系统设置 / 消息通知（画板 `42 · 图标栅格与图标集`）。

### 7.2 后台：新增令牌层

在 `apps/admin/src/styles.css` 顶部加 `:root` 覆盖，不动 Ant Design 组件的结构：

```css
:root {
  --brand-ink: #04302A; --brand: #12A17D; --brand-text: #0A7A5F;
  --accent: #C9F16B; --accent-strong: #B4E247;
```
