# 微信小程序简明说明

## 普通人员

1. 微信登录后授权手机号；唯一匹配已有档案时自动绑定，否则提交人工审核。
2. 在“待办”查看“我必须完成的任务”，进入任务可看到全部必学课件和下一步。
3. 打开图文或 HTML 课件，到达末尾后主动点击完成学习。
4. 全部课件完成后开始考试；退出或断网后再次进入会恢复原考试和已保存答案。
5. 不及格后重新完成补学；次数用完后联系所属部门或项目管理员解锁。
6. 考试通过后预览完整记录，在 Canvas 本人手写签字。正式提交后本人不能覆盖。
7. 在“我的记录”查看完成时间、成绩、考试结果和签字状态；“消息”查看系统提醒。
8. 在“我的”可申请培训订阅提醒，也可提交资料或绑定变更申请。拒绝订阅不影响培训。

## 管理员手机端

服务端确认有管理角色后，“我的”显示“培训管理”。手机端仅用于查看未完成、审核、催办、考试解锁和项目现场确认；课件、题库、模板等复杂配置仍在电脑后台完成。
