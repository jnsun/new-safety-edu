# 项目暂停可恢复而结束不可重新开启

- 状态：已接受
- 日期：2026-09-21

## 背景

旧规则允许关闭后重新开启项目，容易使已经结束的项目经理、安全员和成员关系重新获得当前权限，也会把两个不连续的施工周期混在同一段历史中。另一方面，项目短期停工后仍需要恢复，不适合每次都新建项目。

## 决策

项目暂停是可恢复状态：保留现有成员和项目职责，但暂停期间限制新增成员及关键业务写入。项目恢复时继续使用原成员和职责，并保留暂停与恢复历史。

项目结束是终态：结束全部当前成员关系、项目经理和项目安全员职责，历史只读保留。旧项目以后需要继续开展时建立新项目或新周期，不重新开启原项目。

## 后果

- 状态机必须拒绝从“已结束”回到“正常”或“暂停”。
- 项目结束事务必须同步结束当前成员和职责并使旧会话权限失效。
- 报表和审计可以继续读取历史项目，但不能把历史关系当作当前授权。
- 继续施工时需要新项目或新周期，并重新明确负责人、成员和培训要求。
