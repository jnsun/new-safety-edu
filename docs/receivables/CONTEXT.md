# CONTEXT.md — 企业应收账款台账系统 · 领域术语表

> 本文件只记录业务术语的准确含义，不含任何实现细节。术语在需求拷问会话中逐条敲定。

## 核心概念

### 应收账款模块启用
财务资产部已按稳定组织 ID 绑定、存在当前负责人，且负责人已确认初始财务归属部门和业务字典后的可用状态；条件不全时不能进入财务数据页。

_Avoid_: 空配置上线、仅显示九宫格即视为启用

### 台账记录（Ledger Entry）
一行台账 = **一个合同**。合同编号（contract_no）是台账记录的业务唯一标识：
- 合同编号必填，去除首尾空格后由数据库保证全公司唯一
- Excel 导入按合同编号判重，只允许明确选择跳过或更新
- 同一合同下的多个项目不拆行，归入同一行；项目名称、工作性质、八大板块取该合同的代表值
- 财务对账（发票、回款）以合同为对象，与合同维度的台账天然对齐

## 组织

### 单位（债权单位）
应收账款的**债权主体**（法人），共 4 个：物化院、六勘院、测绘院、禹地公司。回答"这笔钱法律上是谁的应收"——决定按谁的名头对账。单位是**台账记录行上的字段**（每行各自标注），不是部门的上级组织。

### 财务归属部门
台账记录的**责任主体**（内部考核归属）。它由应收账款管理模块独立维护，允许保留改名前或已退出主系统组织结构的历史经营实体名称，不与安全生产管理平台的组织主档同步。

_Avoid_: 主系统部门、平台组织、经营实体主档

每笔新建或导入的台账必须归属于一个当前启用的财务归属部门；停用部门继续承载历史，但不能接收新台账。

### 财务归属部门停用
财务归属部门退出使用后保留原名称和历史台账归属，但不能承接新台账；改名后的主体默认新建为另一个财务归属部门。历史整体转移只能通过单独、可审计的归属迁移完成。

_Avoid_: 删除历史部门、直接改名覆盖历史

**财务归属部门与单位正交**：财务归属部门不隶属单位，同一财务归属部门可持有不同单位名头的合同；一笔台账 = 一个财务归属部门 × 一个单位债权。看板和汇总可分别按财务归属部门（责任口径）和按单位（法人口径）聚合。

### 个人独立核算归属
"翟悟飞""孙勇军"为**合法的台账归属主体**（挂靠项目/个人独立核算），以财务归属部门存在于列表中，不是主系统人员或组织关系。权限与汇总口径同其他财务归属部门。

## 金额口径

### 决算金额
最终结算依据金额。业务惯例：**一般项目不专门做决算，直接以合同额替代**；只有按工作量结算的项目才在完工后单独定案。

### 合同额带入规则
导入/录入时，决算方式非"按工作量结算"的项目，**合同金额自动带入决算金额**（财务仍可手动修改）；仅工作量结算项目允许决算金额留空待定。台账以"决算金额"为唯一结算金额口径，不双轨存储。

### 含税口径
决算金额、开票金额、到账金额、核销金额及所有派生指标均按**含税价**计，同口径直接相加减。

### 决算未定时的计算规则
决算金额为空时：
- 账外应收（决算−开票）、应收余额（决算−到账−核销）显示为空（"—"），**不参与看板与汇总合计**
- 账内应收（开票−到账）照常计算显示（开票、到账均为实际发生额，不依赖决算）
- 财务补录决算金额后，相关列自动恢复计算

### 超收
实际到账超过决算与有效核销后的余额所形成的负应收余额；真实回款继续登记，但该记录进入待核对清单，不自动调整决算或核销金额。

_Avoid_: 拒绝真实回款、自动抹平负余额

### 账内应收 / 账外应收 / 应收余额
- 账内应收 = 开票金额 − 到账金额
- 账外应收 = 决算金额 − 开票金额
- 应收余额 = 决算金额 − 到账金额 − 核销金额
- 三者均为派生指标，不作为台账存储字段

### 回款明细（新增）
与开票明细对称的逐笔回款登记：日期 / 金额 / 备注。到账金额以有效回款明细合计为唯一口径，只读联动；只有汇总金额的历史数据以明确标记的“期初导入”明细承载。核销金额维持累计数不建明细。

### 开票明细
逐笔登记开票日期 / 发票号 / 金额；开票金额以有效开票明细合计为唯一口径，只读联动。开票与回款明细仅应收账款负责人和财务管理员可登记或作废，其他角色只读。

### 最新挂账时间
= 开票明细中**最近一笔开票日期**（确认应收的时点，2026-09-15 决策）。登记/删除开票明细时由系统自动维护；明细为空时保留手填或导入的历史值。

## 角色与权限

### 财务授权主体
应收账款角色、能力和财务归属部门范围统一授予主系统中的 active 正式员工；系统账号只是该人员行使权限的登录凭据，账号换绑、合并或重建不得改变财务授权。

_Avoid_: 按账号授权、为同一人员重复授权、账号合并时丢失财务权限

### 单一当前财务授权
除根据财务资产部负责人身份自动派生的应收账款负责人外，每名人员最多只有一份当前财务授权；该授权包含一个角色模板、附加能力和财务归属部门范围，修改时更新当前配置并永久保留前后历史，不叠加多份财务角色取并集。

_Avoid_: 同时持有管理员报账员只读、多个当前财务授权、覆盖授权历史

### 财务资产部
主系统中以稳定组织 ID 绑定的部门类型组织；它的当前唯一负责人自动取得应收账款负责人权限，组织名称变化不改变绑定关系。

_Avoid_: 按组织名称动态匹配、财务归属部门

### 应收账款负责人
主系统“财务资产部”组织的当前负责人，是应收账款管理模块的最高业务权限主体，可以任命财务管理员和管理模块授权。

_Avoid_: 财务超级管理员、公司管理员

人员成为应收账款负责人时结束其原有普通财务授权并保留历史；卸任后不会自动恢复旧授权，如仍需访问，由新负责人重新授予。

### 财务管理员
由应收账款负责人明确任命的模块管理人员，管理全部日常台账、金额、开票与回款明细、字典及导入导出，并可管理报账员和只读人员；不能任命、修改或撤销其他财务管理员，不能任命或替换应收账款负责人，不能扩大自己的权限，也不能迁移历史财务归属部门或批量改变历史字典口径。

_Avoid_: 公司管理员、组织管理员

负责人更换后，新负责人立即取得负责人权限，原负责人立即失去全部负责人派生权限；已有财务管理员、报账员和只读授权继续有效并提示新负责人复核。任命和撤销均永久记录原因与历史。

### 财务归属部门报账员
按明确授权处理一个或多个财务归属部门台账和催收信息的人员；选择或切换部门不能扩大其服务端授权范围。

_Avoid_: 主系统组织管理员、默认部门用户

报账员只有一个角色模板，实际授权时分别配置编辑基础信息、维护催收、上传附件、新增台账和导出能力，并同时限定可读取与可写入的财务归属部门。应收账款负责人维护全局“报账员可编辑字段白名单”；应收账款负责人或财务管理员再为每名报账员从该白名单中明确选择可修改字段。未选择的字段以及后来新增但尚未由负责人纳入白名单的字段默认只读。决算、金额、开票、回款、核销、配置和授权字段永远不能进入白名单，正式提交后的合同编号仅财务管理员可更正。

_Avoid_: 报账员默认获得全部编辑、通过前端隐藏保护字段、新字段自动可写、把金额字段配置给报账员

### 财务只读人员
只能查看明确授权的财务归属部门；全院查看是独立授予的权限，不从部门选择或主系统角色推导。

_Avoid_: 报账员、全员可见

### 查看全部
只扩大人员对全部财务归属部门的读取范围，不扩大新增、编辑或作废范围；报账员仍只能写入明确授予写权限的财务归属部门，应收账款负责人和财务管理员按其角色拥有全量管理权。

_Avoid_: 全院写入、查看权限推导修改权限

### 财务紧急恢复
公司管理员可以处理财务资产部负责人的正常换任，也可以在负责人缺位、停用或无法履职时执行紧急恢复；两种操作都必须二次验证、填写原因、通知新旧负责人并审计，只改变负责人身份，不授予公司管理员查看或修改财务数据的权限。

_Avoid_: 公司管理员默认财务权限、后台直接改财务数据

正常换任和紧急恢复入口属于主系统的财务资产部负责人管理，不属于应收账款模块入口，并在审计中使用不同动作类型。

### 财务负责人缺位
应收账款负责人暂时缺位时，已有财务管理员继续处理日常台账、金额、导入和报账员或只读人员授权，但不能任命财务管理员、迁移历史财务归属部门、批量改变历史字典口径或扩大自己的权限；公司管理员只看到负责人恢复入口。新负责人就任后恢复完整治理并复核现有授权。

_Avoid_: 整体停摆、公司管理员继承财务数据权限、管理员自我扩权

### 财务授权管理
应收账款负责人可以查看当前所有获授权人员，并可向全公司任意符合第一版人员范围的 active 正式员工授予财务管理员、报账员、只读人员、财务归属部门范围及查看全部等能力；财务管理员可以管理报账员和只读人员，但不能管理财务管理员或扩大自己的权限。授权复用主系统人员和账号，不建立独立财务人员或登录账号。

_Avoid_: 财务用户管理、Supabase 账号

### 财务能力组合
应收账款负责人从系统预定义的查看、新增台账、编辑基础信息、维护催收、上传附件、维护金额与开票回款、导入、导出、配置、授权和查看全部等能力中为人员选择，并同时限定财务归属部门范围。服务端拒绝没有可读范围、没有可写范围却授予写能力等无效或自相矛盾的组合。

维护决算、开票、回款和核销只属于应收账款负责人及财务管理员，不能作为报账员或只读人员的附加能力。

报账员的编辑基础信息、维护催收、上传附件、新增台账和导出能力可以分别开关；字段级编辑范围必须是对应能力、可写财务归属部门、负责人维护的全局字段白名单和该报账员获授字段四者的交集，任何一项不满足都由服务端拒绝写入。财务管理员可以在全局白名单内调整报账员字段，但不能维护或扩大全局白名单，也不能借字段配置获得或授予受保护的金额类能力。

_Avoid_: 任意字符串权限、无范围写权限、报账员金额权限、前端勾选即视为授权

导入和批次回滚仅限应收账款负责人及财务管理员。报账员或只读人员必须被负责人单独授予导出能力，且只能导出原有查看范围；导出不扩大权限并记录筛选条件与行数。

财务授权撤销后，下一次财务请求立即拒绝且模块入口消失，但不终止用户访问其他模块的主系统会话。

## 债权与催收

### 债权状态
**人工维护的催收处置阶段**（正常催收 / 逾期 / 诉讼 / 和解……），不是系统推导值。业务背景：按合同约定的付款期限衡量，账上存续项目几乎全部逾期，自动判定无区分度；该字段的真实用途是让财务一眼看出**处在正常催收还是已进入诉讼/和解等处置程序**。选项由财务在「选项管理」维护。

### 逾期预警
不建系统自动逾期规则；"逾期预警"需求由债权状态的人工维护 + 看板按债权状态筛选/汇总来满足。

### 清收责任人
文本字段，人工填写，通常为部门内人员。与部门归属（行级权限主体）相互独立。

## 记录生命周期

### 财务导入批次
一次经过完整校验、预览和确认后原子提交的 Excel 导入事实；阻断错误使整批不写入，重复合同只能逐行选择跳过或更新，更新不覆盖开票、回款、附件或审计历史。

_Avoid_: 部分成功导入、静默覆盖、删除批次

### 财务附件
附属于一笔台账、访问范围随台账权限变化的私有文件；上传、下载和作废均留痕，正式附件不物理删除。

_Avoid_: 公开地址、仅凭文件路径授权、物理删除

所有业务角色包括应收账款负责人和财务管理员都只能作废附件；确因误传敏感文件、违法内容或安全事件需要物理清除时，只能由服务器运维流程填写原因后处理，并保留文件哈希和处置审计。

### 财务更正
正式保存的台账、开票、回款和导入批次不物理删除；错误事实通过填写原因后作废、冲销或整批回滚退出统计，原记录和操作者永久保留。

_Avoid_: 删除财务历史、覆盖原金额

### 财务操作审计
台账及金额变更、作废、归属迁移、授权、导入导出、附件上传下载和紧急恢复均记录操作者、时间、原因、对象及变更摘要；普通列表浏览不逐次记录。

_Avoid_: 只记最后修改人、无原因高风险操作

### 财务审计可见范围
应收账款负责人可以查看全部财务业务与授权审计，财务管理员只能查看其日常管理范围的财务审计；公司管理员只能查看负责人缺位、紧急恢复或换任等治理记录，不能通过审计读取台账、金额或其他财务业务内容。

_Avoid_: 公司管理员借审计读取财务数据、财务管理员查看超范围审计

### 并发更正冲突
用户提交修改时若目标台账或明细已被他人更新，系统拒绝覆盖并要求基于最新事实重新确认；金额、归属和作废状态不自动合并。

_Avoid_: 后保存者直接覆盖、静默合并金额

### 未结 / 结清
不建物理归档，所有记录永久留在一张台账中。台账总览默认筛选"**未结**"（应收余额 ≠ 0），结清/核销完的行默认隐藏、可一键切换"全部"。

### 核销
**可逆的数值事件，不是终态标记**：新增或调高时不能超过当时未收余额；后续真实回款造成负余额时标记为“核销待调减”，由负责人或财务管理员更正。核销不单设审批流程，但每次变更纳入财务操作审计。

### 财务配置
财务归属部门和业务字典由应收账款负责人或财务管理员新增、排序和停用，已被使用的名称不物理删除；历史台账整体归属迁移仅负责人可以执行。

_Avoid_: 删除在用选项、普通报账员维护配置

在用字典值改名时默认停用旧值并新增新值，历史记录保留旧口径；只有负责人执行带影响预览和审计的批量迁移时才改变历史值。

### 待核对事项
超收、核销待调减、决算未定或明细汇总异常形成的财务处理清单；异常首次产生时通知负责人和财务管理员，但不按日重复提醒，也不自动改变债权状态。

_Avoid_: 自动逾期、每日重复通知、自动修正金额
