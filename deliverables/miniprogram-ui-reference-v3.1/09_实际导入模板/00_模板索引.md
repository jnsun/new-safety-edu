# 实际导入模板索引

| 文件 | 当前能否直接导入 | 使用位置 | 说明 |
|---|---|---|---|
| 正式题库_实际导入模板.xlsx | 是 | Web → 题库与试卷 → 批量导入试题 | 推荐使用 |
| 正式题库_实际导入模板.csv | 是 | 同上 | 便于 AI 和文本工具生成 |
| 每日挑战题_实际导入模板.xlsx | 是 | 先导入题库，再到“日常挑战”启用 | 第一个工作表可直接导入 |
| 每日挑战题_实际导入模板.csv | 是 | 同上 | 不包含挑战分类/难度自动配置 |
| 游戏内容制作草稿_不可直接导入.xlsx | 否 | 无 | 当前系统尚无游戏导入接口 |

## 重要区分

- “正式题库”和“每日挑战”文件都经过当前后端真实导入解析器验证。
- 每日挑战复用题库题目；导入后仍需在管理后台启用挑战属性并设置分类、难度。
- 游戏工作簿只用于长期内容准备。它不是导入模板，不能上传系统。
- 课件模板只用于课件，不得替代本目录任何题库、挑战或游戏文件。
